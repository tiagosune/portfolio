# 🖥️ Portfólio – Tiago Suñé Duarte

Portfólio pessoal desenvolvido com **Angular 21** e **TailwindCSS**, com foco em arquitetura moderna, responsividade e boas práticas de desenvolvimento frontend.

🌐 **Deploy:** [https://tiagosune.com](https://tiagosune.com)

---

## 🧠 Objetivo

Criar uma landing page moderna, performática e responsiva para apresentar meus projetos, habilidades técnicas e fortalecer minha presença profissional como desenvolvedor **Full Stack**.

Além da parte visual, o projeto também foi pensado para aprofundar conhecimentos em:

- Arquitetura SPA
- Angular Standalone + Signals
- Scroll tracking (Scroll Spy)
- Micro-interações e UX
- Responsividade mobile
- Deploy com CI/CD

---

## ⚙️ Tecnologias Utilizadas

- **Angular 21** (Standalone Components + Signals)
- **TypeScript**
- **TailwindCSS**
- **GitHub Pages** (Deploy)
- **CI/CD com GitHub Actions**
- **HTML5**
- **CSS3**

---

## ✨ Funcionalidades

- Scroll Spy dinâmico
- Menu mobile premium
- Toast interativo (copiar email)
- Animações on scroll
- Design clean e responsivo
- Domínio próprio configurado
- SEO básico configurado (meta tags + sitemap + robots)

---

## 📱 Responsividade

O layout foi desenvolvido **mobile-first**, garantindo:

- Menu hambúrguer elegante
- Botões adaptáveis
- Grid responsivo
- Sem scroll lateral
- Experiência fluida em diferentes dispositivos

---

## 🚀 Deploy

O deploy é feito automaticamente via **GitHub Pages** com pipeline de **CI/CD**.

**Build de produção:**

```bash
ng build --configuration production
```
